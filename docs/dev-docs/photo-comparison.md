# 照片综合差异报告

对同一图片清单上的两份 MDRF 生成一份报告，无需重新推理：

```sh
pip install matplotlib
python tools/compare_photo.py images.txt fp32.json fp16.json --output comparison.json
python tools/export_photo_diff.py comparison.json --deployment --output diff-images
```

报告包含三部分：

- `summary` / `differences`：原有的整数框、类别、保存分数的精确比较，以及逐图诊断配对和未匹配预测。
- `residuals`：已配对预测的分数与定位残差统计，另列出未匹配预测的数量、类别、分数及面积分布。
- `perception`：端到端感知差异，继承原容差分析的过滤和匹配语义。

## 残差统计

分数残差以候选减基线为方向，同时报告有符号差和绝对差。数据来自 MDRF 保存的两位小数分数，无法恢复模型的完整浮点精度。

定位残差包括 IoU、`1-IoU`、最大边界像素位移、归一化边界位移、归一化中心位移及相对面积变化。x 方向按基线框宽度归一化，y 方向按基线框高度归一化。零宽高框的归一化统计记为未定义，并在分布中排除。

分布报告样本数、均值、总体标准差、最小值、P50/P90/P95/P99 和最大值；无样本时统计值为 `null`。

分别提供全部配对、发生变化的配对和同类别配对的统计；按基线类别、每 0.1 的基线分数段、基线框面积分组。面积段为 `<1024`、`[1024,9216)`、`>=9216`，单位为原图像素平方。这些是便于描述的固定区间，跨不同分辨率不能直接解释为相同物理大小。

另报告 IoU 损失与基线面积对数、绝对分数差与基线分数之间的 Pearson 相关系数，以及类别转换计数。常量或不足两个样本的相关系数为 `null`。相关性用于探查，不代表因果或统计显著性。

诊断配对继续使用 IoU 贪心匹配，默认 `--iou 0.5`，配对时不强制同类别。残差统计只涵盖这种匹配选中的预测：低 IoU 的大变化会落入未匹配统计，而不是进入配对残差分布。精确结果一致性通过无序多重集合独立判断，不依赖配对。

## 感知差异

两侧分别保留保存分数 `>= --score-min` 的预测，默认 `0.5`。有效配对须同时满足：类别相同、IoU 严格大于 `--perceptual-iou`（默认 `0.9`）、分数差严格小于 `--score-delta`（默认 `0.05`）。在有效配对中求最大数量的一对一匹配。分数边界用 Decimal 比较。

`perception` 保留一致配对数、两侧不一致数量、逐图感知差异、分类统计及阈值穿越等诊断。双方均无保留预测的图片视为一致；没有保留预测时，该侧预测一致率为 `null`。

容差分析已并入 `compare_photo.py`，原 `analyze_photo_tolerance.py` 入口移除。迁移旧命令时将其 `--iou` 改为 `--perceptual-iou`；统一入口的 `--iou` 始终控制诊断配对。`--score-min`、`--score-delta` 含义保持不变。

## 统计图

统一入口生成 JSON 的同时，用 Matplotlib 导出以下四组图的 PNG：

- `residual_distributions`：分数有符号差、分数绝对差、IoU 损失、归一化中心位移的直方图；数量轴使用对数刻度，包含未变化配对。
- `residuals_by_score`：按基线分数段统计分数差与 IoU 损失的均值、P95，每段标出配对数，空段留空。
- `residuals_by_size_and_class`：按基线框面积和类别展示 IoU 损失与归一化中心位移的均值、P95，并标出有效样本数。
- `perception_overview`：端到端一致／不同的图片数量，以及各类别两侧保留预测的不一致比例。它们是模型间差异，不是对真值的准确率。

默认输出目录为 JSON 同目录下的 `<报告文件名去掉扩展名>_plots`；可用 `--plots-dir` 指定目录。重新执行时覆盖同名统计图。JSON 的 `plots` 字段保存图像路径，`residuals.histograms` 保存画图使用的频数和边界，便于核查。分数直方图每个 bin 对应保存分数的 0.01 精度。

## 差异图

导出为单张 Diff 叠加图，共同预测用淡灰细框；基线差异为橙色虚线，候选差异为青色实线，未匹配框加粗。感知模式把容差内的配对作为灰色背景，附近的低分过滤框也以灰色标注，便于观察阈值穿越。

不带 `--deployment` 时沿用数量变化和未匹配两组导出规则；分数差详见 JSON 统计，单纯分数变化不突出着色。带 `--deployment` 时导出所有感知差异图片。导出器也支持旧的独立容差报告。

两份输入应来自完整且成功的运行。稀疏 MDRF 中未出现的图片按零预测处理；报告本身不能区分正常零预测与推理失败，须结合运行日志判断。
