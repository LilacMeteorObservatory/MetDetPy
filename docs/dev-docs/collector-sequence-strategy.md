# 序列维护策略重设计

> 状态：草案  
> 关联：COL-006（waiting_meteor 无界积压）、COL-012（遍历顺序旧优先）、COL-013（匹配无方向连续性）、COL-002（thre2 命名）

## 一、现有策略概述

### 匹配流程（`MeteorCollector.update`）

```
新响应 → 按 active_meteor 插入顺序遍历 → may_in_series(纯距离) → 首个命中即归入
```

- `may_in_series`：新响应任一点与序列近 N 帧历史点距离² < `thre2` 即匹配
- 遍历顺序固定（旧序列优先），无竞争评分
- 无方向/速度判断

### 导出流程（`waiting_meteor`）

```
序列失活 → 进入 waiting_meteor → 等待"全局无活跃高分序列" → 批量导出并时间合并
```

设计意图：持续捕获固定干扰源（烟囱、灯光）的全部响应片段，延迟导出以便 `merge_targets_by_time` 合并为同一记录，提升 recheck 判定准确度。

### 现有问题

| 编号 | 问题 | 后果 |
|------|------|------|
| COL-006 | 导出条件依赖全局"安静"，持续噪声下永不满足 | 内存无界增长 + 导出延迟尖峰 |
| COL-012 | 遍历顺序 = 创建顺序，旧序列"抢走"新响应 | 空间邻近的多轨迹错误合并 |
| COL-013 | 纯距离匹配，方向信息未参与 | 反向运动的响应被错误归并 |
| COL-002 | `thre2` 命名无语义 | 可读性差 |

---

## 二、设计目标

1. **固定干扰源**：识别并及时处置超长持续、几乎不移动的信号源，不依赖全局安静条件
2. **运动学匹配**：基于方向和速度的亲和度评分，兼容流星余迹（响应落在已经过轨迹上的情况）
3. **命名优化**：消除 `thre2` 硬依赖，改为语义明确的参数
4. **不规则点群**：统合云边响应等大面积慢速目标
5. **性能**：维护时间接近常数，不随响应数量线性退化

---

## 三、方案概述

### 3.1 空间网格索引

替代线性遍历，将画面划分为 `cell_size × cell_size` 网格（参考值 64px）。

```
┌────┬────┬────┬────┐
│ 00 │ 01 │ 02 │ 03 │   每个 MeteorSeries 注册到其 bbox 覆盖的 cell
├────┼────┼────┼────┤   新响应仅查询所在 cell 及相邻 cell
│ 10 │ 11 │ 12 │ 13 │   → O(邻域内序列数) 而非 O(全部活跃序列)
├────┼────┼────┼────┤
│ 20 │ 21 │ 22 │ 23 │
└────┴────┴────┴────┘
```

| 操作 | 现有复杂度 | 新方案 |
|------|-----------|--------|
| 查找候选 | O(A) | O(k), k = 邻域内序列数 |
| 点对匹配 | O(A×P) | O(k×P_recent) |
| 插入/移除序列 | O(1) / O(A) | O(cells覆盖数) ≈ O(1) |

### 3.2 运动学亲和度评分

对每个候选序列计算亲和度，取最高分匹配（而非首个命中）：

```
affinity = w_dist · dist_score + w_dir · dir_score + w_speed · speed_score
```

| 分量 | 计算 | 范围 | 说明 |
|------|------|------|------|
| dist_score | `1 - min_dist / max_merge_dist` | [0, 1] | 保留距离约束 |
| dir_score | `cos(2·(θ_new - θ_series))` | [-1, 1] | 周期 π，对 [0,π] 无环绕问题 |
| speed_score | `1 - |v_new - v_series| / v_series` | [0, 1] clamp | 速度一致性 |

达到阈值 `min_affinity` 方可归入；低于阈值则创建新序列。

#### 余迹兼容

流星余迹的响应特点：位于序列已经过的轨迹方向上（后方），而非前进方向。

解决方式——在 dist_score 中区分投影方向：

```
新点 P, 序列末端 E, 运动矢量 V

投影 = (P - E) · V̂         （正=前方, 负=后方）
侧向 = |(P - E) - 投影·V̂|

前方/后方：使用宽松 max_merge_dist
侧向偏离：使用严格阈值（如 0.5 × max_merge_dist）
```

后方容差允许余迹归入，侧向严格限制防止平行轨迹误合并。

### 3.3 固定干扰源在线识别

新增序列属性 **stationarity**：

```python
stationarity = 1 - (位移 / (持续帧数 × 期望单帧速度))
# 完全静止 → 1, 正常运动 → ~0
```

判定条件：
- `stationarity > 0.9`
- `duration > N × max_interval`（远超正常流星持续时间）

处置流程：

```
序列识别为 stationary
  → 标记其占据的 grid cell 为"已知干扰区"
  → 后续同区域新响应自动归入（不创建新序列）
  → 达到导出条件时直接 DROP_FLAG 导出（category=OTHERS）
  → 不进入 waiting_meteor
```

效果：
- 干扰源尽早识别，不占用无界内存
- 空间索引天然支持"同位置归并"
- `waiting_meteor` 只存放真正需要合并等待的候选

### 3.4 不规则点群处理

云边移动响应特征：大面积、多点、低速、方向一致。

识别方式：
- **面积增长率**：bbox 面积增速远超正常流星（流星线性增长，云边是二维扩展）
- **宽高比变化**：流星保持近 1D，云边趋向 2D

处置：
- 面积类序列与直线类序列使用不同 affinity 权重（弱化方向，强化空间重叠度）
- 面积类若 stationarity 较高，合并入固定干扰源逻辑

### 3.5 参数重命名（COL-002）

| 现有 | 新名称 | 语义 |
|------|--------|------|
| `thre2` | `max_merge_dist` | 最大归并距离（像素²） |
| — | `min_affinity` | 最低亲和度阈值 |
| — | `stationary_thre` | 静止判定阈值 |
| — | `stationary_max_duration` | 触发静止判定的最小持续帧数 |

配置兼容：旧配置中 `thre2` 通过兼容层映射到 `max_merge_dist`。

## 四、waiting_meteor 导出条件修订

现有条件（全局安静）替换为：

1. **空间独立判定**：waiting 序列与所有活跃高分序列空间无交叠 → 立即导出
2. **超时上限**：即使空间有关联，等待时间超过 `max_wait_frames`（如 `5 × max_interval`）→ 强制导出
3. **stationary 序列**：不进入 waiting，直接导出

这消除了无界积压的可能性，同时保留了同源合并的窗口。

## 五、权衡与风险

| 项目 | 收益 | 代价 |
|------|------|------|
| 空间网格 | 性能从 O(A) 降至 O(k) | 实现复杂度增加；grid_size 需与 max_merge_dist 协调 |
| 亲和度评分 | 匹配质量大幅提升 | 三个权重需调参；边界情况更多 |
| 固定干扰识别 | 消除内存无界增长 | 阈值设置不当可能误杀慢速流星 |
| 投影方向区分 | 兼容余迹 | 单帧运动矢量噪声大时不稳定 |

关键风险：
- **慢速流星**可能被 stationarity 误判为干扰源 → 需要 stationarity 阈值 + 最小持续时间双重限制
- **运动矢量估计噪声**：前几帧方向不稳定 → 前 N 帧使用纯距离匹配，积累足够历史后再启用方向评分
- **Grid 边界效应**：序列跨 cell 边界时查询可能遗漏 → 查询时必须包含相邻 cell
